# DigitalBiome Crown Void

Current DigitalBiome brand-mark candidate produced from the Figma Foundations exploration.

- Concept: data/root ecology grows into one continuous life structure; the Self is expressed only as negative space inside the crown.
- Production favicon: `public/favicon.svg`
- Figma master mark: `DigitalBiome · Crown Void · Master Mark` (`3511:260`)
- Production variants in Figma: Master / 64 / 32 / 16, with optical stroke correction.
- Light mode color: `#173B33`
- Dark mode color: `#A4B66C`
- SVG cutouts are true transparency via a mask, not white-painted shapes.

`figma-export.svg` is the raw editable Figma export used as provenance. `crown-void-adaptive.svg` is the production-adapted SVG used for favicon integration.
