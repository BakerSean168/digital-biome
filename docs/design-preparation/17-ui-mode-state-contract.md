# 界面切换、URL 与状态契约

日期：2026-10-06。状态：本轮确认方向的实现规格，尚未落入站点运行时。

## 入口

固定底部导航区域使用紧凑的 `TUI / GUI` 控件。当前模式有选中态，另一个模式可以点击；辅助名称分别为“切换到终端界面”和“切换到图形界面”。不弹欢迎对话框，不增加登录要求，不占用 Search 或 Access 的职责。

GUI 中文页面的主要动作采用清楚的词语。模式缩写只出现于切换控件，正文不解释 localStorage、参数或渲染实现。

## 选择优先级

`有效 URL ui 参数 > 已保存偏好 > TUI 默认值`。

| 输入/动作 | 当前效果 | 长期偏好 |
| --- | --- | --- |
| `/tools?ui=gui` | GUI | 不修改 |
| `/notes?ui=tui` | TUI | 不修改 |
| 未指定 ui | 使用已保存偏好；无偏好时 TUI | 不修改 |
| `ui=unknown` | 忽略无效值，按偏好/默认回退 | 不修改 |
| 手动点击 GUI/TUI | 切换当前模式 | 保存用户选择 |
| 存储不可用 | 本次页面/会话仍可切换 | 不报错阻止使用 |

建议本地键为 `digital-biome.ui-mode`，值只允许 `tui` / `gui`。手动切换应移除当前 URL 中旧的临时 ui 覆盖（replaceState），防止刷新后覆盖刚保存的选择；其他参数和 hash 不变。存储失败时可保留新的 ui 参数作为可工作的回退。

从指定 ui 的分享链接进入后，站内导航应继续携带该临时覆盖，直到用户手动选择模式或离开该浏览上下文；不能每次点击链接都跳回长期偏好。不将临时选择写成永久偏好。canonical/站点地图/Pagefind 不为 ui 参数复制内容。

## 地址与浏览状态分工

页面语义路径不变：`/`、`/about`、`/tools`、`/notes`、`/blog`、`/dev`。不新增 `/gui/*` 和 `/tui/*` 内容路由。Project Detail 的 `/projects/...` 与 `/dev/[assetId]` 历史歧义仍是独立决策，不随主题切换默默迁移。

Tools 当前使用 hash 表示类别，例如 `/tools#hosts`；现有 Notes `?tag=` 入口继续有效。后续若把搜索与筛选写入 URL，应采用稳定的对象/条件 ID，不写翻译后的 label，也不包含私有目标地址。

模式切换保留：页面、类别、文本查询、已应用筛选、选中对象 ID、阅读锚点。筛选弹窗的未提交草稿默认不跨模式传播；若切换控件位于弹窗之外，模态期间它本来就不应可操作。切换时关闭浮层并恢复到新视图的对应控件。

阅读位置按内容锚点恢复，不复制 scrollTop 像素；列表按对象 ID 恢复，不复制数组下标。筛选后对象不再存在时，选择首个有效对象；空结果清空预览和底栏对象后缀。关联跳转与浏览器后退应恢复同一份浏览状态。

## 可访问性与初始渲染

选择模式不改变页面语言、文档标题和内容顺序。保持清晰焦点，切换后不能掉回 body 顶部。Tab 仍用于焦点遍历；GUI 不必展示 TUI 的所有键盘提示。

首次绘制前读取偏好，以一个稳定的根属性选择界面，避免先显示另一套 UI。禁止为了两种模式无界输出两份完整知识目录。无 JavaScript 时至少有默认 TUI 的可读内容和真实链接。

界面模式是用户偏好，不是 auth cookie，不需要引入服务端会话。Access 的成功、失败、登出与失效继续由既有服务器契约负责。
