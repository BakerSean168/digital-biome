01 · Content pipeline

知识不是复制进网站，而是被投影出来。

Obsidian 中的 Thought Forest 保持独立可用；Digital Biome 只消费经过索引、可见性过滤和静态构建后的公开投影。

02 · Project storytelling

一个项目，三个不同的公开入口。

Live

真正的生产产品

用于体验完整用户路径，继续部署在项目自己的生产基础设施上。

Project page

面向人的项目故事

GitHub Pages 提供轻量介绍页，解释项目价值、闭环与工程亮点。

GitHub

面向工程的证据

源码、README、ADR、测试、提交与 release history 构成可验证工程履历。

03 · Surfaces

知识、项目与基础设施共享一个导航空间。

Digital garden

支持 Obsidian wikilink、backlink、标签和 Pagefind，让知识网络在 Web 上仍保留关联性。

Project portfolio

项目卡直接消费 Thought Forest 的 public project assets，不再把部署 service 和 source project 混成一个概念。

Infrastructure atlas

公开资产可视化与 protected surfaces 并存，private/internal metadata 不因作品集展示而泄漏。

Personal observability

GitHub 活动、数字资产和运行中系统可以逐步汇入统一的个人信息界面。
